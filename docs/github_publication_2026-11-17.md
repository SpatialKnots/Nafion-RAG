### Проверка при продолжении подготовки

Повторный `git fetch origin` подтвердил отсутствие встречных коммитов в `main`
и рабочей ветке. Сохранённый JUnit проверен: 296 тестов, 0 failures, 0 errors,
2 skipped, то есть 294 passed. Нового запуска pytest на этом шаге не было.

Все 894 версионируемых файла `app/`, `tests/` и `scripts/` сверены с проверенным
кандидатом: 95 совпадают побайтно, у 799 отличаются только LF/CRLF. Все десять
каталогов `reviewed*_glyph_aliases_*.json` входят в побайтно совпадающие.
Первичная строгая сверка показала различия окончаний строк; последующая сверка
явно разрешила только это различие для обычных текстовых файлов, сохранив строгую
проверку каталогов. Иных различий не найдено.

В README, архиве октябрьского журнала и двух записях GitHub проверены 157 локальных
ссылок: отсутствующих целей нет. Из двух документов BOX удалены лишние пустые
строки в конце; проверка подготовленного diff прошла. Научное содержание и
прикладной код при продолжении подготовки не изменялись.

## Limitations

Полный pytest в свежем clone остаётся зависимым от локальных архивов, некоторые
модули не имеют явного skip при их отсутствии. Приватные архивы не добавлены ради
зелёного тестового результата, диагностические ошибки не скрыты. Новая установка,
live API, БД, независимая научная оценка и построчный аудит всей истории не выполнялись.
Существующие исторические scopes вызовов моделей остаются закрытыми.

Репозиторий содержит исходники и документацию, а не готовую БД с литературой.
Для запуска коллега настраивает собственный PostgreSQL, `.env`, корпус и индекс.
Лицензия проекта и права на сторонние данные не назначаются этой публикацией.
Открытые лицензирование/правовые вопросы сохранены в проектных документах.
