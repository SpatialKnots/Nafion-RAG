# ARIADNE: начало исправления количественных отказов

Changed:

После группировки21 отказа реализован первый этап для восьми количественных
вопросов. `quantitative_source_binding_v0.1` использует существующий механизм
source_fact_derived/F-ID: модель выбирает полный F1 либо отказывается; численный
русский текст формируется сервером из заново проверенных исходных полей.
Свободный текст модели и неполные/дублированные/неизвестные ID не допускаются.
Автор, год, article/chunk/page, исходный тип, хеш и адрес каждого поля проверяются.
Единицы не пересчитываются и повреждённые символы не исправляются автоматически.

Новый модуль `app/generation/quantitative_facts.py`; изменения только трёх
существовавших app-файлов: service, answer_facts и query_packet_run. Ветка работает
после сохранения raw evidence, только на остаточном lexical refusal, при отсутствии
другого специализированного контракта; required-concept/relation veto сохранён.
Один исходный chunk содержит полный контракт. Разные наблюдения с конфликтующими
значениями/условиями остаются отказом. Новый поиск, изменение ранжирования,
порогов, схемы БД, PDF, индекса, вопроса, общего промпта или UI не вводились.

Пять конечных source grammars: пороговый интервал; три отношения соль/растворитель
и режимы реакций; число составов и критерий; начальная ёмкость/CE полуячейки;
ёмкость/сохранность полной ячейки с верхним напряжением и числом циклов.
Последние две проверены на построенных контролях, но реальные Peng-вопросы
не допускаются из-за повреждённого raw текста. Три остальные количественные
семейства распознаются только диагностически. Поддержка грамматики не означает
общего научного entailment или проверки корректности эксперимента.

Limitations:

Новые реальные ответы, соблюдение F-ID реальной моделью, стоимость, научная
точность, независимая оценка, полный test suite, deployment и browser layout
не измерены. Общий required-fields guard для этих новых семейств остаётся
not_evaluated; границу допуска обеспечивает отдельный конечный контракт.
Точное текстовое владение и совпадение цитаты не равны научной истинности.
Более широкие перефразировки, таблицы, графические единицы и causal/status
вопросы могут оставаться отказами. Не добавлялось автоматическое исправление
кодировки или автоматическое расширение контекста. Все старые live scope закрыты.
