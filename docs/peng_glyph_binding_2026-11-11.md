# ARIADNE: проверенная расшифровка знаков Peng05/08

Changed:

Продолжение по просьбе «Давай дальше» / «ещё раз попробуй». В двух ранее
отклонявшихся количественных вопросах устранена причина отказа: извлечённые
символы не соответствовали читаемым знакам оригинального PDF. Полностью
отрендерены Poppler и визуально просмотрены страницы PDF4/5. Зафиксированы
неизменный PDF SHA,11 позиционных наблюдений знаков/шрифтов/bbox и исходный
текст. Печатный минус в единице извлекался как U+0001, знак приблизительности
как U+0003, лигатура ft в after — как U+E09D. Имена glyph C0/C24/uniE09D сами
по себе этого значения не доказывают; интерпретация опирается на явный
визуальный разбор источника агентом, не на автоматическое распознавание шрифтов.

Новый `reviewed_glyphs.py` и versioned resource
`app/resources/reviewed_pdf_glyph_aliases_v01.json`:15 операций в двух точных
raw chunks, включая повторные привязки одной страницы в перекрывающихся
фрагментах. Каждая операция содержит исходный offset/символ, расшифровку,
PDF page/text offset/font xref/bbox/font-program SHA. В модуле закреплён SHA
всего каталога. Применение требует совпадения article/chunk/page/source-type
и полного raw SHA. Никаких численных ответов, QA IDs или author/year правил
в расшифровщике и каталоге нет. Это ограниченное исправление данных двух
источников, не общий алгоритм исправления кодировки новых статей.

Изменены три существовавших app-файла: quantitative_facts, UI и experimental
required-fields UI adapter; новый module+resource. В pyproject добавлен resource
в package-data. Данные БД, PDF, индекс, retrieval/ranking, вопросы, thresholds,
общий prompt и provider transport не изменялись. Catalogue не загружается из
клиентского пути и не принимает операции от модели. При отсутствии/изменении
каталога — явный отказ с диагностикой, а не догадка о единице.

Существующие capacity/CE и capacity/retention grammars используют расшифровку
только для известных полных raw sources. Адреса полей и цитаты остаются в
первоначальном raw; нормализованная единица и знак приблизительности несут
отдельную метку преобразования. Факт ёмкости полной ячейки явно сохраняет
приблизительность. Source grammar содержит каталог/исходный PDF SHA и операции;
весь record заново пересчитывается перед F-ID выбором и при сверке с raw registry.
Модель выбирает полный F1 либо отказывается. Численные ответы рендерит сервер.
Оба UI adapters показывают пояснение о расшифровке и точные исходные цитаты.

Limitations:

Это source-specific data repair по уже открытым примерам, не независимая оценка
или доказательство переноса на новые статьи. Каталог доверенный и закреплён
по SHA; runtime не повторяет визуальный просмотр PDF и не выводит смысл glyph
из его имени. Изменённый/new raw chunk не исправляется автоматически.
Источник расшифровки — агентский визуальный разбор, не пользовательская
экспертная приёмка и не научная проверка результатов статьи.
Реальные ответы модели/соблюдение F-ID, стоимость, scientific accuracy,
browser layout, полный test suite, сборка wheel и deployment не измерены.
Исходные извлечённые строки остаются повреждёнными в хранилище и доступны
для аудита; исправление ограничено данным quantitative fact layer.
Старые live scopes закрыты, автоматической отправки нет. План качества75% прежний.

Verdict:

Причина двух отказов Peng05/08 устранена с явной, воспроизводимой привязкой
расшифровки к оригинальному PDF. Готовность14/30 относится к подготовленным
входам, не к числу научно правильных ответов. Следующий отдельный шаг —
табличный контракт Peng06, затем порядок Nambu06 и контекст/сравнение Peng07.
