# Первый внешний эталон: подготовка без отправки модели

Пользователь передал вопрос о зависимости морфологии дисперсии Nafion от
растворителя, четырёхпунктный ответ и ссылку на Kim et al., Macromolecules
2015, 48, 2161–2172, рис. 2–4. Исходный текст сохранён без исправлений:
`records/independent_reference_candidates_2026-10-30_v0.1.json`.
Это внешний пользовательский reference candidate. Метод аннотирования и
независимая экспертная проверка не объявлены. Kim2015 и близкая тема уже
присутствуют в retrieval fixtures; неизвестность темы не заявляется.

## Отдельная сверка источника

Исходный PDF неизменён. Восемь exact windows со смещениями и хешами страниц
повторно совпали со свежим извлечением оригинального text layer. PDF страницы
2–8 отрендерены Poppler и визуально просмотрены ассистентом.

Отдельные замечания ассистента не переписывают пользовательский эталон:

- PDF с.2 / журнальная с.2162: исследована Na-форма NRE-212.
- PDF с.5 / с.2165: microgel для NMP — вероятная модельная интерпретация;
  обсуждаются альтернативные Debye/network fits.
- PDF с.6 / с.2166: глицерин 2,5 мас.%, радиус 22 Å, длина 150 Å.
  2,2 нм и 15 нм — пересчёт единиц ассистентом. Там же >200 нм относится
  к 2,5 мас.% дисперсии вода/2-пропанол 1:1 по объёму.
- PDF с.7 / с.2167: серия соотношений растворителей при постоянных 2,5 мас.%
  отделена от концентрирования. При сохранении 1:1 концентрирование не даёт
  ламеллярного упорядочения, наблюдаемого при испарении с изменением состава.
- PDF с.3–4,8 / с.2163–2164,2168: NMF — апротонное исключение с плёнкой;
  осаждение относится к описанным смесям с одноатомными спиртами.
