# Query-context risk localization v0.1

Prospective stage33 protocol, 22 October 2026. Version `query_context_risks_v0.1`.

Scope: all four preserved stage32 native results, including empty candidates and
deferred pages. Freeze their complete manifest bindings and the verified stage32
source snapshot before execution. No retrieval, embeddings, database access,
generation or external requests. Compare fresh selected-PDF page plans with the
preserved plans; fail on drift. Keep original results immutable.

This is a diagnostic audit, not a replacement admission policy. Replay the old
block builder exactly before analysis. In articles with the existing literal query
anchor, describe whole retained core blocks, one neighboring block on each side,
and the existing transitive protected-group closure, including deferred pages.
Unproven mappings produce no diagnostic windows. Do not cut blocks, shorten
protected closure, raise the existing character/byte ceilings or select a generic
fallback when no anchor exists. No new candidate wire packet is constructed.

Inventory structural triggers in exact registered blocks with raw quotes, offsets
and hashes. A caption/note/numeric/damaged-text trigger locates an observation,
not its complete semantic extent. Preserve all parent diagnostics, including
aggregate page diagnostics not reproduced in individual blocks. No distant trigger
is deemed irrelevant. Protected geometry does not repair scientific notation.

For every visual asset occurrence and every diagnostic window, report intersection
with any selected whole-block or participating protected-group bounding box,
geometric disjointness with scientific relevance unknown, or unknown geometry.
Touching edges and degenerate paths count as intersections. Invalid/unproven
registries never become geometric exclusions. Inventory every asset, including
those not overlapping text; no size threshold, OCR or interpretation of pixels.

Preserve old refusal, qualifiers, byte limits, and the original aggregate page
guard. Report literal interval-union coverage of diagnostic windows separately;
these windows are never candidates or permission to send complete pages.
`selection_changed`, `admission_changed`, `scientific_exclusion_proven`,
`generation_performed`, `external_request_constructed`, `network_ready` remain false.

Publish a searchable local HTML review and full JSON for all four questions, with
exact expandable context text, all assets/triggers/unknown diagnostics and links to
original PDFs and preserved native results. Freeze code, protocol and tests before
the corpus audit; retain repeated deterministic exports separately.

Validation: constructed geometry (near, distant, touching, degenerate, invalid),
protected closure, no-anchor and mapping failures, source identity drift, negative
baseline refusal, complete-page union, escaping, immutable inputs and frozen
binding failures. Software checks are not scientific precision/recall. The four
queries were previously exposed; no independent scientific gold is introduced.
