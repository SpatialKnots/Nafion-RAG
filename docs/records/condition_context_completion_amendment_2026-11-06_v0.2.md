# Context recognition amendment v0.2

After the first frozen-channel measurement, v0.1 did not recognize the exposed
methods block: the PDF contains soft-hyphen/newline splits inside мембран,
методом and обезвоживания. review_v01 and fresh_v02 preserve that unresolved
result; no successful context delivery is attributed to them.

Version v0.2 joins only explicit soft-hyphen plus newline continuations for this
new recognizer, with the original raw addresses and SHA retained. SourceView gets
an opt-in keyword; its existing default and all old fact recipes are unchanged.
No aliases, material IDs, grades, source values, pages, scores or scientific
conditions are added. Add constructed soft-line controls before new measurement.
All other v0.1 bounds and limitations remain.
