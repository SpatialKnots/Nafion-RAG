# Frozen DSC experiment contract v0.1 — stage49

27 October 2026. Implements item 3 of the agreed pre-API plan. Freeze one unchanged
DSC question, admitted stage48 source packet, prompts, reply schema, model/settings,
operational budget, evaluation rules and future result artifacts. No API/status
probe, key lookup, sender, model download, runtime integration or new retrieval/
embedding/database access is allowed. Current user API prohibition remains active.

Use existing local Responses request conventions and endpoint. Reuse the historical
protocol-association alias/settings: gpt-6-astra, medium reasoning, 4096 maximum
output tokens, 180-second timeout; one new future request, no retries or model
fallback. These are frozen operational choices, not claims of current provider
availability, model snapshot, pricing or schema support. No monetary estimate or
input-token estimate is invented. Limit actual serialized request bytes by the
existing 100000-byte ceiling. Preserve store=false, stream=false, truncation=disabled
and default service tier. The model alias may resolve differently at execution;
record the provider's actual returned model and usage without guessing.

Reconstruct stage48 admission and stage47 packet from their unchanged parents.
Require source eligibility, exact wire/regions and all source guards. Build the
full provider envelope locally; freeze exact UTF-8 request bytes, SHA256, endpoint,
system prompt, source wire, reply schema, runtime, code and protocol. Check both
the serialized request and decoded input contexts against existing full-page
guards, including source-region interval union. Local PDF paths and complete-page
registry remain local. This validates the local envelope contract, not a live API.

Reply proposals account exactly once for six fields: instrument, sample_handling,
measurement_environment, flow_rate, temperature_range, temperature_programme.
Each field is present/not_found_in_context/ambiguous/unsupported with a diagnostic.
Present fields cite unique exact quotes within M1; bibliographic contexts cannot
supply measurement conditions. No numeric/unit conversion, source-text repair,
cross-article pooling or sample-specific assignment is allowed. All-present gives
answer_proposal, some-present partial_proposal, none-present abstention. Abstention
does not prove source absence. Restore page/layer/PDF identities and absolute
offsets from the exact registered quote. Free diagnostic text is unverified.

Evaluation separates transport/completion/schema, source integrity, field coverage,
and scientific correctness. Exact quotes, citation roles, complete field accounting
and consistent abstention are automatic checks. Truth, entailment and scientific
accuracy remain unreviewed; no independent reference labels or accuracy metrics
are manufactured. Exposed/constructed controls are development evidence only.

Freeze an explicitly unexecuted result template: zero transport attempts, unknown
response/model/usage/cost, no fake raw response. The future executor must reserve
the sole attempt durably before transport; timeout/transport failure retains that
consumed slot and never triggers an implicit retry. Save exact request bytes,
attempt record, raw response/error bytes (credentials redacted where applicable),
request ID, actual returned model/usage/service tier, elapsed time, parse/evidence
errors and artifact hashes. Missing usage stays unknown. Preserve raw data before
parsing; failures cannot be represented as successful abstentions. No live executor
or attempt reservation is implemented in this offline contract stage.

Implement a separate offline response-inspection helper for supplied response files.
It never sends requests or spends/resets the future call budget, records origin as
offline_supplied_response, saves raw bytes before parsing, and retains expected
parse/source errors explicitly. Constructed response tests are not provider runs.
No constructed response is inserted into the real unexecuted experiment output.

Prepare/run/export require new paths, full frozen-binding validation, deterministic
reconstruction and byte-identical repeat exports. CLI denies audited CPython
connect/DNS/sendto operations before application imports and records attempts and
completion even on failure; not an OS/native firewall. Tests challenge altered
question/source/admission/request/model/budget/prompt/schema, missing/duplicate
topics, invented/ambiguous quotes, wrong citation roles, abstention, malformed or
incomplete Responses envelopes, and preservation of raw bytes/errors/usage.

Local searchable HTML shows the full request, prompts, budget, evaluation and
unexecuted status. Preserve a byte-identical stage48 copy, including the stage47
packet and one-document/eight-column TAC HTML with explicit unimplemented fields.
No XLSX or writable per-Term workflow. Verify links/PDF navigation, source hashes
and repeated exports; report actual test results. Live sending remains item 4
