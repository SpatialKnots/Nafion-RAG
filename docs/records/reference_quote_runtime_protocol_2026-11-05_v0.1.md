# Explicit-reference retrieval and bounded quotations, v0.1

User asked to continue with Q01/Q05. Local development and verification only;
no external model/OAuth calls, downloads, live slots or resends. Existing native
requests/outputs/gold/manifests remain immutable. Freeze current runtime first.

General reference parsing uses one explicit Latin surname/coauthor/year citation.
Resolve uniquely using registered metadata within the requested collection and
ALL existing filters (including library, tag, source layer/type). Ambiguous or
unresolved references preserve the baseline. Author match is not answer admission.
Read chunks only from the resolved eligible work. Rank the first source chunk,
requested body roles (composition/cycling, preparation/conductivity table) and
original-query body-token coverage. Never use gold IDs/pages/expected numbers.
Reserve method and table roles before any cutoff; original top-k and raw text,
page/layer identities stay intact. Inactive reference queries issue no new DB query.

Two finite quotation-only answer families: (1) composition of a fluorinated
ether/carbonate electrolyte plus cycling of two explicitly named cell pairs;
(2) ethanol-free Nafion dispersion preparation for a named sample plus conductivity
comparison with a named commercial dispersion. All supported words/constraints
must be accounted for; unsupported additional qualifiers/numbers block this path.
Parse raw abstract / dissolution-procedure / conductivity-table spans with explicit
section boundaries. Keep every raw character, units, conditions and footnotes.
Require same resolved work and all requested body roles; no cross-article joins.
Missing/ambiguous boundaries, unperformed/future/hypothesis-only contexts or missing
sample rows/units remain blocked. No semantic ownership or independent verification
is claimed. Distinguish literal source association from a scientific confirmation.

Eligible answers may select only exact attributed source quotations. Native enum
and existing exact/citation validation must forbid additions/paraphrases/wrong
citations. All mandatory quotation roles must be selected together, or the output
is rejected; abstention remains allowed. This finite contract may replace a lexical
RU-query/EN-source refusal only when complete. Existing numeric thresholds stay
unchanged. Original raw evidence remains the displayed citation; derived native
payloads retain hash/offset bindings to the original chunk. Registry verification
must explicitly validate the binding, never silently equate JSON with raw text.

Before measuring exposed questions: constructed negatives for wrong author/year,
ambiguous works, body citations, source/library/tag filters, wrong cells/sample,
missing table/unit/footnote/step, negation/hypothesis/future, extra conditions,
partial selections, tampered contracts, and raw immutability. Then all five cases
and76 older frozen-channel service replays with explicit baseline drift mapping.
Actual fresh read-only searches/preparations for Q01/Q05; stop at native send
boundary, no external calls. Show unsent request size/settings and source anchors.
Synthetic selections and fake transport responses are never actual model answers.
Do not tune after results without a separately versioned design. Full mypy,
appropriate tests, source hashes/pages/spans and static review required.
