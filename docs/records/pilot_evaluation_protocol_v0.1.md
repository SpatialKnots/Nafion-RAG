## New versioned evaluation contract

`records_pilot_reference_v0.1` supports multiple reference records per case.
The context is a source-only candidate bundle and its exact file SHA-256.
The author, declared author kind, reference kind, scope description, exhaustive
scope declaration and exposure-to-predictions declaration remain explicit.
`independent_annotation_declared` requires a declared human and a declaration
of annotation before outputs. These are caller assertions, not authenticated
independence. An unannotated case cannot contain expected records and cannot
be treated as an empty scientific reference.

Each reference record has its own deferred dimensions. Unknown/ambiguous
expectations remain deferred; no metric drops them from the expected count.
Existing twenty-dimension exact text/status/anchor/representation/linkage rules
are reused without number/unit normalization or new scientific tolerances.
Linkage compares role and anchor coverage, not semantic entailment. Duplicate
role proposals must not disappear through dictionary conversion.

Predictions are explicitly declared saved candidate bundles. Validate their
evidence contract and require exactly the same registered source regions as the
reference context. Saved bundle integrity does not itself attest a model's raw
response/runtime. Missing/failed/malformed inputs remain unavailable with their
expected record counts; source identity mismatches stop the evaluation.

Use deterministic maximum bipartite matching, with at most one prediction per
reference and one reference per prediction. First match complete agreements;
then augment assignments with compatible deferred references, allowing exact
ties to be reassigned without unmatching an already matched fully evaluable
reference. Repeated predictions cannot increase matched reference count.
Known mismatches retain all pair-level diagnostics. Unmatched available
predictions/references are finite-reference disagreement/omission counts, not
automatically established scientific errors.

Precision/recall are finite-reference exact-agreement rates. They are null if
any case is unannotated/unavailable or any expected dimension is deferred.
Recall is also null when exhaustive supported-scope annotation is not declared.
Empty denominators yield null, not 0% or 100%. All expected records remain in
the summary, with unavailable and deferred counts separately reported.
No automatic scientific-admission state or independent-scientific-accuracy
claim is created by this evaluator.
