# Query context selection v0.1 — stage40, 24 October 2026

Written before new selection outcomes. Scope: all four frozen stage39 tasks,
their full audits, stage38 parent packets, complete stage37 diagnostics and all
ten historical TAC documents. This is an explicit CHANGE OF SELECTION, not a
lossless reserialization. Entire parents remain byte-identical in local sidecars.
No runtime routes, retrieval, database, inference, external lookup or PDF edits.

Version `query_context_selection_v0.1`. Finite query families: conductivity and
thermal analysis, using existing property cues and query aliases. Protocol intent
uses literal method/measurement/conditions/programme cues; preparation/conditioning
intent uses literal preparation/atmosphere/equilibration/before-measurement cues.
Each literal hit retains exact Unicode offsets. No score, top-k, arbitrary budget
truncation or scientific positive classification is introduced.

First restrict candidates by explicit article/material qualifiers from the existing
query-qualifier grammar. All such required mentions must be satisfied in the SAME
article using frozen baseline Evidence and bibliographic metadata only. Unknown
metadata, absent mentions and parser warnings remain explicit; they do not license
borrowing evidence from another article or imply corpus-wide absence. Baseline
refusals are never promoted. Qualifier method mentions do not replace the new
query-family inventory. An unsupported query family selects nothing and reports
its finite-scope limitation, with the full source kept locally.

Within eligible articles, property-family hits establish literal article anchors,
not scientific adequacy. For protocol intent, seed complete registered blocks
that have a query-family hit plus a literal method/measurement cue, or a compatible
explicit method-family hit in the anchored article. For other supported queries,
seed all query-family-hit blocks. When preparation/conditioning is explicitly
requested, additionally seed preparation/conditioning indicators and original cues
in anchored articles, regardless of event support/guard state. Negated, reported,
clipped or unclassified matching source is NOT removed because of its state.
This avoids requiring a pre-resolved scientific relation before selecting text.

Closure selects every member of each existing co-preservation unit touched by a
seed. Thus formulas between method fragments, unresolved source-order/cross-page
links and protected groups are indivisible. No sentence is repaired and no table
cell interpreted. No missing physical neighbor is fetched. A protected group can
be transmitted whole or deferred whole, never partially. Unmatched/unknown source
is explicitly deferred locally, never declared irrelevant or scientifically absent.

Wire keeps exact block text, identities/page/layer/offset references, original
flags and document registry. References keep their original parent positions;
they may be sparse. Explicit dependency_refs/unit_refs identify filtered lists.
Only original windows whose entire membership survives are listed as such; every
partial/deferred original window is accounted for locally. Complete selected units
are always present. New local ledgers account for every old block/event/window,
all guards and every protected group; losses of parent-window coverage are reported
even if all development requirements survive. Scientific loss/recall is not measured.

Checks inspect the exact serialized wire, decoded visible source text and source
page interval unions. Ceiling stays 100000 bytes. Closure may exceed it or assemble
a complete page: retain text and block the candidate. Keep every inherited refusal
(including historical scope/size/full-page failures), add explicit selection-not-
scientifically-validated diagnostics, and keep network_ready, generation_performed,
external_request_constructed false. Fewer selected full pages cannot upgrade old
admission. Numeric interval/step/instrument-accuracy semantics remain unresolved;
the complete original blocks, not isolated extracted temperature tokens, are selected.

Freeze source-bound development checks/code/tests/protocol before measured run.
Required checks retain the known impedance/equilibrium/formula chain and complete
preparation block, preserve raw numeric context, avoid preparation-to-measurement
inheritance, keep protected members all-or-none, preserve all refusals, and select
no substitute for missing Istomina/DSC or Mars/regolith evidence. These are exposed
assistant development checks, not independent human scientific gold.

Exclusive prepare/run/export create separate local artifacts and deterministic
HTML with search, full expandable selected units, deferred-source ledgers, original
PDF links, all input hashes and a separate eight-column TAC table for all ten
documents. All old source and unknown/ambiguous cases remain accessible. No manual
Terms resolution or writable review forms. Byte reduction or passing development
checks does not establish scientific retention, token/cost savings or model quality.
