# Article-level development cohort and source scope v0.1

21 October 2026. ARIADNE S02/S04/S05 preparation after records stage17.

## Purpose

Prepare source-supported, explicitly assistant-authored screening proposals and
complete stored-page task packets for the existing Li-Nafion conductivity pilot.
The scope remains conductivity of the lithium form with the author's property
wording. Total ionic conductivity is not renamed lithium-ion conductivity.
This is development preparation, not independent eligibility or scientific gold.

## Frozen inputs and evidence

Verify the existing source-only packet with the stage16 auditor before export.
Keep all documents, all available selected-text pages, original/selected PDF
hashes, page/layer identity, exact quotes and zero-based Unicode offsets.
Screening assertions must cite exact spans in registered source regions. Preserve
the source inventory and a byte-identical screening sidecar in each output.
Recheck all source artifacts and PDFs after export. Never overwrite outputs.

Use a separate strict versioned screening sidecar: author kind must be assistant;
every document has one entry, a rationale, explicit provisional status and source
evidence. Unknown remains unknown. Statuses distinguish proposed primary
conductivity article, proposed supplement, related dissertation, other-property
context and unresolved. These are source-screening interpretations, not measured
scientific suitability or authenticated bibliographic metadata.

Document relations cite evidence on both sides. Exact-PDF identity is an observed
file identity only; same DOI is a metadata diagnostic only. A proposed supplement
link does not establish identical measurements. A dissertation is never treated
as an extra independent publication. Do not merge distinct works, assert absent
measurements or generate independent train/test splits from these proposals.

## Article-level task packets

For every proposed primary article, export an unchanged copy of its complete
source-only bundle. Attach proposed supplements as separate source bundles and
retain document boundaries. Record every original PDF page as selected text,
empty selected text or missing stored page; the task accounts for all pages,
not just retrieval hits or previous oracle fragments. Do not copy screening
labels into the source-only bundles or manufacture candidate measurements.

The task is not a completed extraction. Every page retains an unresolved
non-text completeness state: stored text does not establish coverage of figures,
image tables, units or scientific notation. Keep proposed source relationships,
measurement duplication, article-wide recall and eligibility unaccepted.
No full-page context is sent to a model; this stage makes no inference/API call.
Future bounded extraction requires a separately frozen plan and reports.

## Completion and limits

Export deterministic JSON, manifests and a searchable local HTML table retaining
all supplied documents and exact evidence/PDF links. Count proposed primary
documents separately from independent eligible publications (unknown), supplied
PDFs and supplements. Do not claim the target of 10–15 publications is reached.
Preserve exposure as development-only. No human annotation/time observations,
scientific accuracy, admission, production ingestion/retrieval/schema changes
or Terms user-resolution workflow are introduced.

Verify strict coverage, unsupported relations, exact spans, changed source/PDF
rejection, repeat-export equality and HTML escaping using constructed tests.
Run actual packet exports twice, compare output hashes, and check local PDF
targets and source/page coverage. Report code tests separately from scientific
and browser acceptance.
