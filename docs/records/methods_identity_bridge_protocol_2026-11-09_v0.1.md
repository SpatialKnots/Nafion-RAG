# Проверка Methods identity bridge, v0.1

9 ноября 2026. Пользователь разрешил проверить определения в Methods и
разметку figure_caption. Это read-only offline audit, не новая runtime admission.
App/runtime/DB/index/PDF/filters/source_type не изменять. Model/OAuth/slots0.

Материал: неизменённые Lin2020 Abstract/Introduction PDF1, Material Preparation
PDF3 и Conclusion PDF7 из frozen corpus. Сначала зафиксировать все193 app
Python/YAML bindings, raw sources, PDF hashes/fresh pages/anchors, текущие
пять/76 service baselines и пять native bodies. Ранее раскрытые источники
и assistant interpretations не являются independent gold.

Проверять конечную цепочку, не совпадение1.35 M:

1. Существующая composition recipe из Abstract: base salt/concentration,
   solvent components/volume ratio, additive/concentration, reported total.
2. Явные aliases: dimethyl carbonate (DMC), полное имя добавки (LiDFOB).
   Только raw definitions; chemical dictionaries/model inference не применять.
3. Material Preparation: три solvent/ratio entries и три base codes,
   с явным respectively и общей base concentration/salt.
4. Три дозы добавки were separately added to BASE to obtain три PRODUCT codes.
   Ordered parallel-list pairing — отдельное явно объявленное правило этого
   diagnostic candidate. Оно не объявляется общей semantic ownership.
5. Target code взять только из явного we have designed a functional electrolyte
   CODE в ограниченном Conclusion. Найти literal code в PRODUCT list, затем
   сравнить соответствующую дозу, additive alias, base salt/concentration,
   весь solvent list и volume ratio с Abstract. Сумма сверяется с уже
   source-bound reported total; цифры внутри CODE не интерпретируются.
6. CE из Conclusion и capacity из Abstract сохраняют свои source/conditions/
   status. Температуры из подготовки/EIS не переносятся. CЕ span должен лежать
   в том же bounded Conclusion после явного target code.

Метки CODE сравнивать через raw-span NFKC+whitespace-only: структурный дефис
перед newline не удалять. SourceView может удалять hyphen-newline при
распознавании слов; сырой CODE и обратные addresses должны оставаться точными.
Не менять SourceView или оригинальный PDF ради этой проверки.

Все3 источника одной работы/одного text_layer, original source_type сохраняется.
Mixed source_type допускается только как вход read-only диагностики; текущий
source_role_assembly guard не меняется и не обходится.
Каждая связь имеет hash/article/chunk/page/raw span. Figure-caption audit:
воспроизвести current classifier, показать конкретный raw trigger и сравнить
с ограниченным Material Preparation span, без reclassification/writeback.
Визуально проверить PDF1/3/7, сохранив distinction source extraction/figure layout.
