# Offline source-region ownership audit v0.1

Scope: add a separate, bounded source-region diagnostic layer for the already
saved v0.2 event proposals and twelve constructed real-source fixtures. No model,
OAuth, DB, retrieval, slot reservation, provider change or runtime integration.
Preserve native replies, historical parser verdicts, schemas, prompts, fixtures,
source annotations, original PDFs and all consumed/closed budgets.

The new algorithm must consume raw source text and validated selected spans,
without case/question matching, assistant reference labels or reliance on the
model's event kind. Recognize only a declared finite RU/EN operation vocabulary.
Use a mapped recognition view for line-end word hyphens/soft hyphens; retain exact
raw offsets/quotes and never alter stored extraction. Reuse the existing finite
statement splitter unchanged. A local region with one recognized operation is
evidence of locality only, never scientific proof of ownership.

Split explicit sequence markers. Split coordinated operation clauses only when
separate duration expressions precede/follow the conjunction; shared trailing
values remain unresolved. Multiple operation lexemes, unrecognized operations,
shared/analogous/referential expressions, recognized abbreviation-boundary
ambiguity in the inherited splitter, conditional/negated scope or spans
crossing regions must remain visible and unresolved. Flag a selected field in
a different explicitly typed operation region as a diagnostic, not a final
scientific contradiction or rejection. Do not pick a nearest operation, borrow
values through relations, repair the proposal or upgrade answerability.

Audit duration/condition selections; missing fields remain unevaluated, not
validated absence. Separately compare declared duration relations with finite
explicit adjacent bound/range/approximation cues in raw source. Preserve cues
outside the selected span as diagnostics. Bare numbers do not prove an exact
requested value. Unrecognized strict bounds, distributed context or duration
syntax remain unresolved. No unit conversion or inference from numeric equality.

Test cross-sentence borrowing, same-sentence drying/storage, repeated identical
numbers, same-class operations on different samples, shared trailing conditions,
back references, negation/conditionals, unknown lexemes, numeric bounds, OCR-like
breaks, original-input immutability and untrusted restored/catalog drift. Confirm
that changing only model kind cannot change source-derived ownership diagnostics.
The three live errors and all source pages are exposed development evidence;
do not claim independent accuracy or a general semantic validator.

Deliver a separately versioned report/HTML for all twelve declared cases and all
five source works in the eight TAC columns. Keep actual live proposals separate
from constructed fixtures; do not pool their counts. Show all exact source/value/
operation spans, region diagnostics, frozen raw proposals, full registered pages,
source identity, old formal verdicts and working original-PDF links. Verify old
bindings/manifests, native replay and original PDFs offline with socket operations
prohibited. Independent annotation/evaluation and semantic ownership validation
remain open; the user is not required to resolve Terms or individual cases.
