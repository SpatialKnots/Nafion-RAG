# Evidence-gap audit v0.1 — prospective stage46 protocol

Written before new gap-audit outcomes. Input questions are the four exact frozen
stage45 questions. Baseline artifacts, selection, source text, metadata, refusals,
and admission remain immutable. The Mars-regolith question is a negative control,
not an observation. No API, model, embedding, retrieval, database, download, new OCR,
or production integration is allowed.

Inspect full original-PDF text of the ten registered parent documents. Search each
question's original document set, plus a separately declared Istomina candidate for
the DSC question. Do not pool evidence across articles. The candidate is outside
the historical scope and needs exact first-page title/byline/publication anchors
and a pinned PDF hash. Those source-development anchors were exposed during
planning, not obtained from independent scientific annotation. A failed identity
check leaves attribution unresolved. A filename is never identity evidence.

Reuse the unchanged ingestion text extractor and registered-block geometry reader.
Assign new local capture layer IDs to unregistered pages; never imply these IDs
came from the database. Require exact agreement for all historical page texts and
layer IDs where registered. Extraction/PDF failures propagate; empty text pages
and unproved block mapping are explicit. No graphical completeness is inferred.
Save every page's exact text, hash and blocks, with document/PDF/page/layer identity.
New full-document captures are separate source supplements, never replacement
generation packets. Preserve all old guards, origin, condition, and sample audits.

Finite, versioned RU/EN regular expressions identify only lexical endpoint
candidates: conductivity, impedance, DSC, sample, equilibration, atmosphere,
temperature/programme, and negative-control qualifiers. Preserve all matches and
complete matching blocks with exact Unicode offsets. No normalization, numeric
interpretation, graph reading, cross-event joining, or scientific linking occurs.
Cross-block/cross-page occurrences are not joined. A cue match is not a supported
scientific assertion: negation, citations, bibliographies, and layout risks remain
uninterpreted in new source hits. Historical diagnostic authority remains linked.

Produce per-question, per-document checklists. Candidate status distinguishes
`supported_in_packet` (exact source presence only), `found_outside_packet`,
`not_found_in_inspected_scope` (searchable text only), `not_inspected`, and
`source_identity_unresolved`. Required scientific relations always have a separate
`relation_unresolved` disposition unless independently established in a future
stage; this audit never establishes one. Mixed samples, repeated IDs and generic
methods cannot resolve applicability. Preparation atmosphere cannot be promoted
to measurement environment. Required evidence and next checks are specified for
each gap; negative controls do not require inventing a missing measurement.

Freeze code, protocol, registration, dependencies and development checks before
prepare/run. Checks cover all questions and unchanged refusals; exposed or
constructed checks are not scientific gold. Verify exact question strings against
the checked-in definition without invoking retrieval. Record complete-document
text coverage independently from visual QA. Any visual inspection is a separate
source-review artifact and does not upgrade algorithmic states.

Prepare/run/export require new paths, verify all parent/input/output hashes and
code inventories, revalidate source spans and page extraction, and compare exports.
CLI denies audited CPython socket/DNS operations before application imports;
record attempts and completion even on failure. This is not an OS firewall.

Searchable local HTML includes every question, every required checklist, every
source hit and exact context, coverage and unknowns, and working PDF links. Keep
historical TAC metadata byte-identical. A separate TAC HTML contains all ten
historical documents plus the candidate, explicitly marked with verified raw
identity anchors or unknown fields, unimplemented TAC/Terms, and full first-page
source evidence. No XLSX, manual per-Term workflow, fabricated metadata, acceptance,
accuracy, or corpus-wide absence claim is introduced. Report tests only after run.
