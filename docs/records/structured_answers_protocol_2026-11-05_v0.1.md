# Request-local facts and Russian presentation, offline implementation

User explicitly chose proposed items1+2: structured value/unit/sample/operation/
condition/qualifier/source records and a readable Russian answer with expandable
original excerpts. This is not a new live-test scope. Model/OAuth/slots0; all old
scopes/native/API/gold/PDF/manifests remain immutable. Freeze runtime first.

Initial production scope: the four existing bounded families (reference
electrolyte composition/cycling, reference aqueous-dispersion preparation/
conductivity, Li2O layer/bulk/conditions, EC/SL cycles/structure). Q03 and other
unsupported question types retain their existing runtime. No schema migrations,
stored fact reclassification, retrieval/index/threshold changes or extra model
calls. Existing app.facts numeric candidates are not promoted to owned scientific
facts: they lack these sample/operation/value bindings.

Introduce explicit versioned source_fact_derived records. Facts are request-local
textual bindings from finite source grammars, NOT independent confirmations.
Every scalar/condition/qualifier has a raw chunk hash/citation/article/chunk/page
range and exact source character span; unknown fields stay null/diagnosed.
Preserve raw numeric/unit spelling, preparation versus measurement roles and
reported/literature/hypothesis/system-arithmetic states. Never borrow values or
conditions from other works, neighbouring operations or footnotes without an
explicit source rule. Reject ambiguous/incomplete parses. No expected benchmark
IDs/authors/pages/values or user reference in parsers. Ambiguous extracted units
must remain literal/unknown; no silent S N cm-1→S/cm rewrite.

Use deterministic audited Russian templates, with explicit Decimal/Fraction
arithmetic and rounding for any ratio/total derived by the system. Each rendered
claim is recomputable from raw source and field bindings. Only complete bundles
use the new path; unsupported/ambiguous facts fall back to the existing bounded
path with explicit diagnostics, never arbitrary generated facts or admission.
English requests retain their existing presentation until an English renderer is
implemented, while diagnostics may report the supported-language boundary.

Reuse one provider call and ASCII selection: IDs F1..Fn, all mandatory records
exactly once with exact citations, or abstention. No generated prose/numbers or
normalization/typo repair enters the rendered scientific answer. Validate
server-held facts/payload/source bindings, reject tampering/partial/unknown/
duplicate/wrong-citation selections before rendering. Raw sources are retained
in citations and UI details; human-readable answer must not display transport
JSON or mix source quotation with system summary. Mark unknown conditions and
arithmetic visibly where material. Public response fields unchanged; add only
explicit versioned metadata/source type.
