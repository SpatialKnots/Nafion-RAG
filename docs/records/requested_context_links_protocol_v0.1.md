# Offline experiment/context/source links v0.1

Scope: the eight exposed cases bound by requested_information_audit_20261029 /
review_v02. No networking, API/OAuth, DB, retrieval, embeddings or runtime changes.
Verify the parent manifest and every parent binding, including historical inputs,
PDFs and consumed slot records. Preserve old outputs. Write a separate versioned
report and searchable HTML with all cases and all source documents/TAC columns.

The prototype proposes a requested duration or equilibrium criterion, explicit
sample labels, author/year work constraints, property/method mentions, stage and
literal temperature. This is a finite grammar, not a complete semantic parse.
Record raw question spans. Bibliographic matching uses recorded author/year
metadata, never body references or guessed titles; missing metadata is unresolved.

Inventory exact source statements containing duration/unchanged-spectrum cues.
Map those statements to the selected evidence and, only when unique, to an exact
substring on the registered original/OCR page with article, page, selected text
layer, layer ID, PDF path and PDF SHA256. Preserve extraction noise and retain
failed/multiple page mappings as unresolved. No repaired text or cross-sentence
coreference. Multiple values, stage/sample conflicts, missing requested cues,
negations and hypotheses stay diagnostic. Same-statement co-occurrence is only
an unverified proposal, never entailment or scientific admission.

Map answer expressions only to their cited source candidates. Numeric matching
is literal with whitespace/case normalization, without unit conversion or
invented equivalence. A criterion may have different wording but remains a
criterion, not a numeric duration. Keep claim-context conflicts and incomplete
identity explicit. Provider-filtered/malformed replies and valid abstentions
retain their historical layer; selected-source inventory cannot validate an
answer that was never produced.

Constructed adversarial tests must cover preparation, soaking/drying, other
samples/articles/methods/temperatures, negation, hypotheses, mixed stages/samples,
conflicting values, missing metadata, uncited matches, page/layer/quote tampering,
ambiguous mapping and cross-sentence associations. They are software regression
fixtures, not independent scientific gold or estimates of model accuracy.

All output states are unresolved or unverified proposals. No acceptance threshold,
answer rewrite, scientific rejection, forced abstention or production schema
change. The finite grammar does not validate every condition or relation, and
must not be installed as a scientific gate. A general semantic coverage method
and independent evaluation remain open after this prototype.
