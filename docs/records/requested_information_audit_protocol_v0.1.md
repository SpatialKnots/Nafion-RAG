# Offline requested-information audit v0.1

Scope: eight previously exposed GigaChat results from the four-case answer batch,
two-case abstention check and duration/criterion pair. No API, OAuth, database,
retrieval, embedding or production change. No previously consumed slot can reopen.
Read saved native replies with the current strict parser and citation validator;
record their format/error layer separately from requested-information diagnostics.
Verify manifests, request identity, PDF hashes and append-only registry results.

The experiment tests one deliberately narrow diagnostic: for a finite RU/EN
duration-question grammar, does a structurally valid, non-abstaining answer
contain a lexical numeric/common-word-number duration expression? Preserve exact
question/claim/evidence substrings and raw offsets. Return three diagnostic
states: outside grammar, no expression detected, expression present/unverified.
No state is a scientific pass, proof of absence or permission to generate.

Important adversaries: a year, citation ID, frequency, temperature or length must
not serve as a time expression; a preparation time, another specimen/article,
negated measurement or hypothetical duration must never become scientific
acceptance merely because it contains a number with time units. Finite grammar
misses (e.g. unrecognized languages or implicit/worded times) remain explicit.
Do not concatenate unrelated claims into a new number/unit expression.

Filtered/native-malformed replies and false/empty-claims abstentions bypass the
duration diagnostic. Preserve exact finish_reason, parser error, original public
status/body and raw content. In particular, blacklist is an observed provider
filter reason, not evidence about its trigger or scientific insufficiency.

Review is assistant-authored development evidence, not independent scientific
annotation or accuracy. Generate JSON and searchable HTML retaining all eight
cases, full requests/replies/traces/source registry, all selected documents in
the agreed TAC columns and original-PDF links. Preserve old manifests/results.

Before considering any runtime use, a future semantic design must represent the
requested quantity and sample/article/method/stage/conditions separately, bind
candidate values to exact source anchors and keep relation/negation/conflict or
unparsed requirements unresolved. Lexical mentions are insufficient to establish
those links. No generic threshold, answer rewrite, forced abstention, new schema,
model call or hard-coded answer is authorized by this offline experiment.
