# Compact source context protocol v0.1 — stage38, 24 October 2026

This contract is written before real compact outcomes. Scope: all four immutable
stage37 questions, their complete native packets, all ten historical TAC documents
and the six existing assistant development retention checks. No new retrieval,
database, metadata lookup, provider invocation or scientific labels are permitted.

Version: `compact_context_packet_v0.1`. Stage37 remains the complete diagnostic
authority. A byte-identical `diagnostics.json` copy accompanies each model-facing
`wire.json`; its semantic content is also bound by a canonical SHA256 in the wire.
Canonical JSON uses UTF-8, sorted object keys, no ASCII escaping and no whitespace
separators. The exact wire file has no trailing newline; measured bytes equal the
actual file length. `packet.json` holds the wire plus local validation results.
No external request or provider payload is constructed.

The projection preserves every selected block, exact Unicode text, source order,
page/layer/physical PDF identity, page offsets, every original window and its core
references, every active structural dependency and every co-preservation unit.
Repeated text at different offsets remains separate. Explicit column names describe
readable tables. All integer references are one-based positions in their declared
lists; contexts and dependencies retain the stage37 ordering. Full block IDs,
window hashes, dependency details, events, cue/guard spans, visual registries,
per-window asset matrices, baseline Evidence, unselected blocks, original local
PDF paths and all diagnostics remain in the hash-bound local authority.

The wire exposes distinct event states, unconfirmed proposed kinds, guard reason
codes and boundary flags per block through a shared dictionary. These are summaries
of local diagnostics, not scientific classification or a claim that each guard
applies to the whole block. Page flags expose mapping uncertainty, parent and
unlocalized diagnostic presence, visual registry presence and open boundaries.
The model cannot claim to have inspected omitted diagnostics. There is no new
property/method/condition association, sentence reconstruction, table interpretation
or scientific completeness claim. Source text is untrusted data, never instruction.

Validation replays the unchanged stage37 builder and compares the entire projection.
Every original context must expand byte-for-byte to its old source text. Before
any new output, frozen inputs/code hashes and current PDF registration are checked.
Scope and exact-source TAC validation reuse stage37. All old blockers, including
historical size failures, remain inherited. The new actual byte check is a separate
field: a smaller representation cannot upgrade a scientific or admission refusal.
The existing 100000-byte ceiling is unchanged. Oversized source is never clipped.

Full-page safeguards inspect actual serialized JSON, decoded model-visible source
text, and interval union on each registered page. JSON escaping, node references,
table packing and split windows cannot bypass complete-page detection. Assembled
coverage must equal stage37. Any complete page remains blocked. `network_ready`,
`generation_performed`, `external_request_constructed` are always false.

Prepare binds complete stage37 outputs, their inherited source/code bindings,
new code/tests/protocol, metadata and the existing retention challenges before
measurement. Run creates exclusive local outputs; export deterministically rebuilds
reviews from captured packets. No prior stage output is overwritten. HTML includes
search, expandable exact contexts, full diagnostic links and a separate eight-column
TAC review containing every document in scope. Missing values and proposals remain
explicit; no writable per-Term form or human confirmation is introduced.

Report old/new wire bytes and exact source bytes per question, block/window/dependency
counts, literal/decoded/assembled page matches, current size checks, retained blockers
and existing retention checks. Byte reduction is engineering evidence only; tokens,
cost, latency, model quality and independent scientific accuracy are not measured.
