# Source-role assembly: явное обозначение электролита, v0.1

9 ноября 2026. Пользователь разрешил следующий шаг пункта4: правила сборки
composition/capacity/CE из разных разделов одной работы. Работа офлайн.

Первая конечная область: уже выбранные raw parents одного uniquely resolved
explicit author/year work, один source_type и зарегистрированный text_layer.
Без нового retrieval/DB, расширения top_k/context budget или снижения thresholds.
Прежний полный fact path имеет приоритет и остаётся неизменным.

Связь устанавливается только по явному локальному маркеру `Electrolyte LABEL.`
в начале строки (возможно после ABSTRACT:). Все support spans соответствующей
роли должны находиться в том же ограниченном абзаце после маркера. LABEL
совпадает буквально во всех трёх ролях; число в LABEL не интерпретируется.
Общий article_id, совпадающая концентрация или анафорическое «it» недостаточны.
Композиция должна находиться в том же first-page parent, который подтверждает
указанных авторов/year. Поддерживаются существующие recipes, не новые значения.
Requested cells должны точно совпадать с cell владельцами capacity/CE.
Никакие условия/числа между ролями не переносятся; неизвестные поля сохраняются.

Абзац ограничивается пустой строкой/следующим маркером/section heading/концом
parent и4500 raw chars. Отрицание, будущее, гипотетическое/предлагаемое/чужое
действие или другой образец в нём не допускаются finite status guard.
Разные labels, cell/value/conditions/status кандидаты, разные works/layers/types,
неполный source или отсутствие identity дают явный unresolved.
Повторы идентичных фактов в overlapping chunks дедуплицируются детерминированно,
а не считаются независимыми подтверждениями.

Сохраняются исходные author/year/front-matter, supported query constraints,
required concepts/relations и все F-ID/citation/recomputation проверки.
Новый complete contract — отдельное versioned finite admission rule; неполный
assembly не разрешает генерацию. Старый gate baseline и причины сохраняются.
Extractive provider и English requests не получают новый путь. Ни одного
дополнительного model call, retry или fallback transport не вводится.

Assembly payload содержит версию, question/reference/layer context, literal
label и marker/role bindings. Каждый record помечен версией assembly: удаление
контракта не должно позволять standard parser принять неподтверждённую сборку.
При чтении пересобирается весь пакет из raw parents; cross-parent/context/ID/
field/marker/version tampering отклоняется. Каждый parent независимо сохраняет
свою raw hash/identity/page/text binding. Public top-level schema прежняя.

Контрольные наборы до edits:

1. Прежний runtime и81 full-service/native baseline; старые outputs неизменны.
2. Реальные неизменённые Lin Abstract/Methods/Conclusion: отсутствие прямого
   label в Abstract означает unresolved. Methods-мост и solvent/additive aliases
   не угадываются. Этот материал exposed, не independent gold.
3. Constructed positive: source roles разнесены по явно помеченным paragraphs
   одной работы и одного LABEL. Отдельно labels/cells/значения/статусы, absence,
   ambiguity, different work/layer/type, unsupported query, identity и tampering.
   Это проверки поведения, не новые опубликованные данные.

Критерии: complete constructed case достигает actual service/ASGI F-ID path,
abstention сохраняется; negatives отказывают до provider или строго отклоняют
повреждённый output. Реальный Lin без явных role labels не объявляется успешно
собранным. Прежние5+76 traces/native bytes должны совпасть; нет измеренного
прироста на них. Если изменился контекст — остановка и отдельный read-only
DB/rollback preparation, без отправки. Проверить actual decoded native quotes,
все raw bindings, affected tests/Ruff/full mypy app, PDFs и HTML/TAC33/eight columns.

Не разрешены реальные model/OAuth calls, новые slots/downloads/deployment.
Independent evaluation, scientific ownership, общий scope пункта4 и75% прогресс
не закрываются. Иные label форматы и настоящий Methods bridge остаются отдельной
будущей работой. После результатов менять scope только отдельной версией.

Assessment note (после первого измерения, без изменения rules): в сохранённом
Lin Methods parent source_type=figure_caption, остальные два main_text.
Полный реальный пакет блокируется scope guard ещё до label check. Отдельно
проверить неизменённые Abstract+Conclusion без Methods: они должны остаться
unresolved из-за отсутствия явного label. Не исправлять классификацию источника
на лету и не переобозначать разные причины как одно доказательство.
