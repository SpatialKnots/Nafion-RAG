## Contract and baseline

The model returns each target exactly once. It proposes conductivity,
thermal_analysis or unknown and selects sentence IDs for property, method and
conditions; origin is own_work_proposal, reported_work_proposal or unknown.
All selected IDs must be unique within a field and belong to the same source
block. A known property needs property evidence. Unknown can retain conflicting
evidence. Restore full exact source sentences locally; never generate or repair
quotes, parse numbers, infer row ownership or silently fill prior candidate fields.
Sentence identity proves source location, not scientific entailment or applicability.
All model results remain proposals; old guards and uncertainty are never promoted.

The independent-of-model local baseline uses a finite conductivity/DSC lexical
family inventory from the same full block. A unique family plus stage27
scope_proposal yields co-context proposal only. Otherwise it abstains. No method
or condition link is inferred by this baseline. Do not send baseline labels,
old policy states, reference answers, local PDF paths or hashes to the model.
The API sees only declared target IDs and exact source sentences.

## Prospective execution budget and reproducibility

Before real inference freeze this protocol, new code/tests, parent source/output/
code/PDF hashes, cases, local baseline, exact native requests, source page registry
and settings. Constructed tests may run before freezing. No prompt, source,
threshold, expected label or schema tuning after real output inspection.

At most **five** sequential HTTPS requests to the fixed Responses endpoint,
one per case, model alias `gpt-6-astra`, medium reasoning, default service tier,
strict JSON schema, store=false, stream=false, truncation disabled, no tools,
4096 output/reasoning tokens per request, total cap 20480, timeout 180 seconds
per request and 100000 serialized request bytes. No temperature or seed.
If all selected cases exceed the call budget, fail preparation instead of clipping.
Reject any formatted request containing a registered complete stored page.
Preparation is offline; it may replay old raw local results but sends no request.

Use existing configured credentials without printing or persisting secrets.
Persist the frozen request before transport and raw response before parsing.
Preserve request/response IDs, returned model, native usage and elapsed time.
No retry, response repair, model switch or budget extension. Stop at first failure
and retain every remaining case as unattempted. Refusal/incomplete/transport/schema/
source failures are failures, not scientific abstentions. A new invocation uses an
exclusive output directory and a fresh declared budget; do not resume a consumed
run. store=false does not establish Zero Data Retention. Provider endpoint behavior
and structured outputs were checked in official OpenAI Docs before implementation.
