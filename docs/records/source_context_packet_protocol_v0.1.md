# Source context packet v0.1

Prospective stage37 protocol, 23 October 2026. `source_context_packet_v0.1`.

## Goal and boundary

Prepare a losslessly reconstructible representation of source context for later
answer evaluation. Store a registered PDF text block once and refer to it from
every original whole-block context. Preserve existing protected table/layout
groups, surrounding blocks, complete source events and negation/reported-work/
modality/boundary diagnostics. These are co-preservation dependencies, not verified
scientific property/method/condition assignments. Do not turn unknown associations
or spatial disjointness into proof of irrelevance.

Keep the complete unchanged risk-preparation result locally. Do not modify old
JSON contracts, OCR/text/chunking, metadata, thresholds, retrieval, providers or
original PDF files. New wire-proposal and result schemas are explicitly versioned.
No network/model calls or paid comparisons are part of this stage. Generation is
disabled and scientific admission remains `not_evaluated`.

## Construction

Start from a no-generation stage34 risk-preparation envelope. Replay the unchanged
block preparation and risk audit; reject differences. Require every retained
window to expand to its exact original text by concatenating complete registered
blocks in source order. Deduplicate only identical source identities (article,
original/selected PDF hashes, physical page, selected text layer ID/hash, absolute
offsets), never identical strings from different locations or experiments.

Retain every diagnostic window, its core membership, all associated trigger/asset
relations and stage27 source events. Keep protected-group members, captions,
context blocks and interleaved source blocks together when the group intersects a
window. Reject partial group closure. Group labels do not establish header/row/unit
semantics. Reconstruct exact full windows without whitespace normalization.
Additionally connect adjacent registered blocks when the unchanged source-event
registry marks a terminal or initial sentence boundary unproven (or has no events).
Take transitive closure with protected groups. This conservatively keeps intervening
formula fragments between split method text and its continuation, without declaring
a reconstructed sentence/paragraph or a scientific relationship. Across pages use
only an existing physical next page with the same article, selected PDF identity and
layer kind; missing neighbors/mixed layers stay unresolved. Never concatenate across
different articles just because their text matches.

No sentence, numeric value, instrument or condition is copied into a new scientific
record. Preparation/conditioning/measurement event proposals stay distinct.

For every registered page/block report whether represented or retained only in the
unchanged local baseline. Preserve unproven mappings and no-anchor pages with full
source and explicit reasons. Cross-page adjacency within the same article/PDF/layer
may be recorded as an unresolved boundary, never automatic table continuation or
method applicability. Missing adjacent pages remain explicit; do not fetch them
silently. Preserve all visual assets/diagnostics, including outside-window assets.

The wire proposal contains unique source text nodes, ordered context references,
protected-group dependencies and diagnostics. Local file paths and full source-page
registries stay outside the wire. Keep complete local registries for offline
verification. No claim that the wire is complete scientific evidence is allowed.

Re-run both literal full-page and aggregate interval-union checks on unique nodes;
splitting pages across nodes or duplicate contexts cannot bypass them. Keep the
existing 100000-byte wire ceiling; diagnose excess without clipping or raising it.
Preserve every old refusal/blocking reason and add unresolved dependency/scientific
completeness findings. A structurally valid representation does not grant network
eligibility. Report actual characters and UTF-8 serialized bytes only. If comparing
deduplication, its denominator is concatenated stage33 diagnostic-window text, not
the earlier selected baseline, token billing or answer quality.

## Frozen scope and checks

Use all four unchanged stage34 native results, including empty/no-anchor and old
refusal cases. Freeze protocol, code/tests, full predecessor/PDF/input bindings and
source-based retention challenges before new packet outcomes. Challenges refer to
exact source spans for method, equilibration, table units/rows/notes and guards
where present; missing query evidence remains missing. They are development
retention checks, not independent human scientific gold or new accepted measurements.
No outcome-driven sample exclusion, alias tuning or reference repair.

Verify current PDF registrations against saved plans without new extraction layers,
retrieval, database access or model requests. Changed historical source may bind
only to matching verified source-archive bytes with explicit mappings. Private data
drift must fail. Save native packet JSON, exact expanded contexts and all blockers.
Repeat exports independently and require byte-identical JSON/HTML/manifests.

Produce searchable read-only local HTML for every question, all source blocks,
dependency groups, full reconstructed contexts and unknown diagnostics. Include a
companion TAC table for all ten distinct documents in this scope with Title,
Authors, Journal, Year, Abstract, Conclusions, Terms and original-file links. Reuse
the frozen stage35 metadata/history/TAC proposals only after exact source validation;
label their separate versions, unconfirmed status and absent fields. Do not require
per-Term or per-case user decisions.

Tests cover exact reconstruction, same-text/different-source identity, protected
closure/interleaved blocks, guard/event preservation, zero contexts, missing pages,
unproven mappings, malformed/foreign references, old refusals, full-page unions,
oversize preservation, drift/exclusive exports, HTML escaping and search. Inspect
browser rendering and local link targets where supported. Targeted regression,
Ruff and mypy are required; expand to the full runtime suite only if runtime wiring
changes. End with a report of actual results and scientific/UI limitations.
