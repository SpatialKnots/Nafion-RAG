# Three-case GigaChat event-selection pilot v0.1

The user requested execution after the proposed offline schema/citation checks
and bounded three-case GigaChat experiment. New scope: exactly the curated cases
dispersion_hold_then_spectra, impedance_equilibrium_criterion and
protonation_missing_time from real_experiment_cases_v0.1. This does not reopen
any earlier model slot. No production /answer, schema, retrieval or DB changes.

Prepare all native requests before sending. Freeze code/tests/protocol, source
dataset and existing report bindings, original page/layer/PDF identity and each
request hash. Archive bound source code. The model receives the exact question,
unchanged source statement catalog and a finite lexical duration-atom inventory;
no reference answer, scientific annotation, previous output or known-case ID is
sent. Catalog IDs restore raw quotes and number/unit strings with exact offsets.

Separate experimental strict schema: one target event plus at most two other
events. Each proposes kind, contexts, sample, operation, duration, conditions and
completion criterion. Unknown/uncertain fields have no selected IDs. Validate
source IDs/order/uniqueness, status consistency, field membership in declared
contexts and exact raw catalog reconstruction. These checks do not establish
event assignment or scientific truth. Never repair a response or force a status.

Use current GigaChat-2-Max / GIGACHAT_API_PERS and the existing TLS-verified
GigaChat transport. At most three OAuth exchanges and three model POSTs, one
per case, no retry/fallback/account reads/purchases/scope upgrades. Existing
1200 output-token and 120-second per-HTTP limits; native bytes <=100000 per case,
no clipping. This is a token ceiling, not a monetary cost cap. Reserve append-only
global request-SHA slots before OAuth. Failures/interruptions consume their slot.
Known sandbox socket restriction requires ordinary execution escalation.

This is direct experimental extraction, not an ASGI /answer run. Preserve exact
native bodies and raw replies before parsing, native model/finish reason/usage,
formal diagnostics, timing and slot records. Do not manufacture HTTP 200/502
results when the reused transport does not expose native success HTTP metadata.
Filtered/incomplete/malformed responses remain failures, not scientific abstentions.

Prespecified source-reading expectations (not independent gold): the dispersion
cell explicitly has a two-hour hold before spectra; the Kayumov excerpt gives
unchanged spectra as equilibrium criterion but no numeric dwell; the protonation
excerpt gives two hours for H2O2 cleaning, not HCl protonation, with separate drying
and storage times. Review target assignments and exact selected atoms separately
from formal validity. Wrong-stage source-exact selection is a scientific failure
even if local integrity passes. Do not tune after observing these responses.

Offline replay must consume saved raw replies only, without DB/network/model
calls. Deliver searchable HTML for all three cases, full requests/replies/catalogs,
source diagnostics and all selected works in the eight TAC columns with original
PDF links. Assistant review on exposed cases is not independent accuracy,
causal evidence of superiority or runtime scientific acceptance. No further calls
are included after these three slots.
