# Records stage26: frozen condition-rule transfer probe

21 October 2026. ARIADNE, `records_condition_transfer_v0.1`. Offline test of the
unchanged stage25 source-event policy on other declared article tasks.
**Zero new model calls. Zero new measurement records.**

The observed result is a transfer limitation: **all 851 probe units returned
no_literal_cue**. The separate Kayumov control replay exactly reproduces the five
stage25 events. Software integrity passes; cross-document cue recognition is
not demonstrated. No-cue output does not establish absence of experimental
conditions, scientific recall or article ineligibility.

## Frozen design and declared scope

[Protocol](records/condition_transfer_protocol_v0.1.md).

The preparation packet was saved before executing or inspecting real transfer
rule outputs. It freezes the protocol, adapter/CLI/tests, exact existing stage25
rule hash, all parent inputs and the entire document/page/block inventory.
No aliases, English cues, boundary rules or thresholds were added after results.
Original PDFs, stored text, previous contexts, candidates, schemas, role outputs,
scientific/review states and prior execution code remain unchanged.

The complete Kayumov task is excluded from transfer denominators. All other
stage18 tasks are included, using unchanged full-page source bundles and the
stage19 registered-block mapping. A proposed supplement remains part of its
primary task group rather than becoming an independently eligible publication.
These sources were development-exposed before this probe; freezing the present
experiment does not turn them into independent scientific holdout data.

Every page and registered block is included, including bibliography, headings,
no-keyword text and the 25 pages historically deferred for layout risks. All
52 page registries prove exact full-page coverage by 851 blocks with ordered,
non-overlapping ranges, unique block numbers and finite positive boxes. No mapping was deferred
in this run. Earlier layout/source diagnostics stay attached to every page.

The adapter passes each complete registered block as an exact derived SourceRegion
to the frozen source_events function. It does not join blocks, repair text or
hyphenation, create paragraph continuations, choose keyword/top-k inputs or send
sources to a model. A local raw-rule probe does not activate a deferred page for
extraction. Paragraph adequacy and per-result applicability remain not_established.
This tests only the source-event function, not table-temperature binding or the
entire candidate-projection pipeline.

The separate control is the exact original Kayumov method region, including its
incomplete final sentence. Its event content must equal the saved stage25 catalog
before transfer execution can continue. Control events are never pooled with
transfer counts or treated as independent validation.

## Observed results and interpretation

All 851 blocks return no_literal_cue. All 2252 emitted events retain kind
unclassified: 1636 unsupported_clause and 616 incomplete_source. The last label
is the frozen rule's punctuation/boundary state, not a newly measured count of
scientifically truncated paragraphs. Blocks can contain headings, references,
table fragments or prose whose boundary is unsupported by the narrow policy.

The frozen rules recognize anchored Russian source phrases developed for one
method block. They do not recognize the following English source wording in this
probe. This is a qualitative explanation based on post-hoc assistant inspection,
not independent annotation or a computed recall denominator:

- Sanginov, PDF page 3, registered block 14 begins `AC conductivity was measured`.
  The full exact block also contains cooling-mode measurements and isothermal
  equilibration wording. Its unchanged outcome is no_literal_cue.
- Istomina, PDF page 4, registered block 14 begins
  `Through-plane lithium conductivity was measured`. The exact block also states
  `equilibrated` and `for 24 h at 25 ◦C before measurement`. Its unchanged outcome
  is no_literal_cue.

The full source blocks, absolute offsets, page/layer/PDF identities and unchanged
rule events are saved separately in qualitative_examples_v01.json. These examples
were selected after observing the result and do not change the frozen scope,
rules, outputs or metrics. Their text has not been projected onto any table
measurement or admitted as a scientifically validated condition.

Scientific precision/recall remain null. Unsupported events and no-cue units are
abstentions, not false negatives against an independently annotated gold set.
The result supports keeping the current policy bounded to its development source;
it does not support claiming a general multilingual conditions extractor.

## Validation

Changed:

- Added `app/records/condition_transfer.py`: complete transfer task/page/block
  accounting, exact derived source units, deferred-mapping diagnostics, unchanged
  rule execution and separate exact control replay.
- Added `app/records/condition_transfer_export.py` and
  `scripts/records_condition_transfer.py`: separate prepare/run phases, frozen
  code/source manifests and deterministic searchable read-only HTML/JSON export.
- Added 38 constructed tests and the prospective versioned protocol. Existing
  stage25 rules, old candidate and database schemas, extraction, ingestion,
  retrieval, scientific states and original PDFs are preserved.

Tests run:

- New targeted suite: **38 passed**, 4.12 seconds. Cases cover full-scope source
  accounting, task exclusion, proposed supplement counting, English abstention,
  Russian cues, clipped source, Unicode/source identities, mapping gaps/overlap,
  duplicate blocks, invalid boxes, missing pages, code/manifest/source drift,
  preparation without rule execution, separate control replay, deterministic
  exclusive export and HTML escaping.
- `ruff check app scripts tests`: passed.
- `mypy app`: passed, 132 source files.
- Full regression: **1791 passed**, one existing Starlette/httpx deprecation
  warning, 136.55 seconds. Run outside sandbox with a dedicated stage26 temporary
  directory; JUnit results are preserved.
- Two real exports are byte-identical. The packet byte copy, 716 frozen input
  bindings, unchanged rule hash, original PDFs, full-page/block coverage, all
  2252 exact event spans and separate five-event control verify.
- Static HTML verification found 52 page rows, 851 block cards, 55 existing local
  PDF/artifact links and all exact full-page/block quotes. Search is present;
  there is no writable resolution form. Browser acceptance is not claimed.

Limitations:

- Previously development-exposed documents, no independent gold or scientific
  precision/recall. Two primary task groups do not establish independent studies.
- The unchanged literal Russian policy has no recognized transfer events here;
  it must not be presented as a general multilingual extractor.
- Exact PDF blocks are not guaranteed to be complete scientific paragraphs.
  Existing layout/graphics/cross-page risks and missing source-type metadata are
  not repaired or promoted by local probing.
- No measurement record, new field filling, method-to-result applicability,
  scientific acceptance, model/API call or database/review-store write occurs.
- Post-hoc source examples illustrate a limitation; they are not new gold labels
  or performance metrics. Static HTML checks do not establish browser acceptance.

Verdict:

The frozen transfer experiment is complete and reproducible. It exposes a real
boundary of the current source-specific policy: the control replays, while all
other-task blocks abstain. Keep v0.1 unchanged. Next work requires a separate
versioned multilingual scope policy with explicit source boundaries and negation/
reported-work handling, followed by another separately frozen comparison.
Independent scientific evaluation remains separate; technical tests cannot
substitute for it.
