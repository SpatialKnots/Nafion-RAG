# ARIADNE: рыночные ориентиры стоимости ревью кода

Текущая смета проекта по последующему поручению пользователя — **4000000 ₽**;
эта услуга сохраняется на **250000 ₽**.
[Смета на 4 млн ₽](cu_budget_4m_2026-11-17.md) заменяет промежуточные общие
итоги ниже. Сборка/подготовка внутри BOX+, сами исправления отдельно не оценены.

Дата проверки: 17 ноября 2026. Статус: пользователь утвердил **250000 ₽
на разовый аудит кода и архитектуры основных сценариев** в рабочей смете.
Это не коммерческое предложение и не заключённый договор.

## Что именно оценивается

Разовый инженерный аудит кода и архитектуры выбранных рабочих сценариев
с отчётом, воспроизводимыми замечаниями и планом исправлений. Исправление
всех находок в стоимость аудита автоматически не включается.
Сборка/настройка/проверка готовности конкретного BOX остаются внутри сметы BOX.
Независимый предметный аудит специалистом после шести месяцев за не более
100000 ₽ по ГПХ — другая, уже выбранная пользователем работа.

Нужен специалист с практикой Python/FastAPI/SQLAlchemy/PostgreSQL,
интеграции LLM API и проверки подобных приложений; наличие химической
квалификации для инженерного ревью не предполагается. Химическая
правильность ответов не доказывается заключением о качестве кода.

## Публичные ориентиры подрядчиков

- [CodeHub](https://itcodehub.ru/): опубликованные начальные ставки Python
  Senior от 3500 ₽/ч, Senior+ от 4300 ₽/ч; финальная ставка определяется задачами
  и объёмом. Это услуги компании, не подтверждённая ставка частного лица по ГПХ.
- [BPAdevelop](https://bpadevelop.ru/services/audit-koda/): экспресс-аудит
  от 90000 ₽, комплексный от 250000 ₽. Исправления описаны отдельно от диагностики.
- [Code Pilots](https://code-pilots.ru/news/audit-informacionnoy-bezopasnosti/):
  заявляют аудит кода/архитектуры 200000–600000 ₽; это предложение подрядчика
  с акцентом на безопасность, не медианная цена рынка и не смета ARIADNE.

Публичные цены «от» не являются счетами, подтверждением свободного специалиста,
его квалификации или статистикой завершённых сделок. Налоговый состав и
документы каждого предложения нужно уточнить; ставки компаний нельзя молча
считать суммой «на руки» по ГПХ. Конкретные подрядчики не проверены и не выбраны.

## Расчётные варианты для ARIADNE

Следующие часы — оценка ассистента по текущему устройству и предполагаемому
заданию, а не измеренная трудоёмкость и не обещание прочитать каждую строку.
Для сопоставимости используется интервал ставок 3500–4300 ₽/ч из прайса CodeHub;
это начальные ставки, а не доказанная верхняя граница рынка.

| Формат | Оценка часов | Расчёт стоимости, ₽ | Граница |
| --- | ---: | ---: | --- |
| Экспресс-ревью критичных сценариев | 20–30 | 70000–129000 | Архитектура и выборочная проверка; ограниченный охват |
| Целевой аудит основного процесса | 40–60 | 140000–258000 | Импорт → БД/индекс → поиск → rewriting/ответ → источник/UI, отчёт |
| Углублённая проверка расширенного состава | 80–120 | 280000–516000 | Более широкий охват; сплошная проверка всего репозитория всё равно не гарантируется |

Рабочий пример целевого аудита — **60 часов × 4000 ₽/ч = 240000 ₽**:

| Работа | Предлагаемые часы |
| --- | ---: |
| Разобрать архитектуру и согласованные сценарии | 8 |
| Проверить импорт, очередь, БД и обращение с файлами | 12 |
| Проверить поиск, current-answer/rewrite, источники и guards | 16 |
| Проверить API/UI, обработку ошибок и обращение с секретами | 8 |
| Проверить выбранные тесты и воспроизвести находки в согласованном контуре | 8 |
| Подготовить отчёт, приоритеты, оценку исправлений и обсудить выводы | 8 |
| **Итого** | **60** |

Это описание будущей услуги, не результат уже проведённого аудита.
Реальные платные обращения к модели в таком задании требуют отдельного
согласованного объёма; наличие API-бюджета само по себе их не разрешает.
Исправления делает команда по отдельному плану либо они отдельно оцениваются
исполнителем; обязательства «исправить всё» за 240000 ₽ не принимаются.

## Предложение к смете

**250000 ₽ на разовый аудит кода/архитектуры основных сценариев утверждены
пользователем.** Расчётный пример выше даёт 240000 ₽ и остаётся обоснованием
порядка цены, а не отдельной суммой поверх бюджета. Разницу не оформлять
свободным резервом. Для договора выбрать конкретное предложение с составом
работ, ценой и расчётом организации; обязательные затраты нельзя добавлять молча.
При бюджете около 100000 ₽ можно обсуждать ограниченный экспресс-формат,
не обещая полный аудит 44 тыс. строк приложения, всех тестов и скриптов.

Прежние 400000 ₽ в [рабочей смете](cu_grant_budget_working_2026-11-13.md)
заменены утверждёнными 250000 ₽. Сценарий с BOX+ уменьшен на 150000 ₽
до 4170719 ₽ + S_BOX+. После отдельного утверждения 0 ₽ новых лицензий/данных
вместо 150000 ₽ текущий сценарий — 4020719 ₽ + S_BOX+, где S_BOX+ — неоценённая
подготовка внутри сметы BOX+.
Решение не разрешает контакты, передачу кода или заключение договора.
Ранее предложенное снятие строки было слишком категоричным: внешнему
инженерному ревью есть конкретное назначение, а сумма должна следовать заданию.

Changed: зафиксировано утверждение пользователем 250000 ₽, рабочая смета
пересчитана. Размер рабочего дерева и расчётные варианты сохранены, код не изменён.
Tests run: подсчёт файлов/строк и арифметика часов/ставок; локальные ссылки проверены.
Limitations: полноценное ревью, замеры качества тестов, запросы предложений
и проверка исполнителей не выполнялись; цена будущей версии неизвестна.
Verdict: 250000 ₽ утверждены для рабочего бюджета разового аудита основных
сценариев; исполнитель/договор ещё не выбраны, исправления оцениваются отдельно.
