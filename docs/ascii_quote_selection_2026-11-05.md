# ASCII IDs и серверная подстановка исходных цитат

Changed:

После согласия пользователя выполнен офлайн-фикс для ограниченного пути
`reference_quote_derived`. Внутренний контракт — `explicit_reference_quotes_v0.3`.
Модель получает исходные цитаты с короткими ASCII IDs `S1`, `S2` и возвращает
только IDs с соответствующими citation IDs либо отказывается от ответа.
Сервер проверяет полный уникальный набор, точное написание IDs, привязку к
источнику и подставляет свои исходные строки. Пробелы, Unicode-подмены,
неизвестные IDs, неполный набор, дубликаты и неверные ссылки отклоняются.
Нормализация или исправление ответа модели не выполняются.

Изменены четыре модуля: `reference_quotes.py`, `gigachat.py`,
`lithiation_overview.py`, `service.py`. Сохранены извлечение исходных фрагментов,
проверки авторов/года, raw SHA/offset/citation bindings, обязательные роли,
пороги и публичные поля API. Проверки точного исходного текста выполняются и
после подстановки. Другие контракты сохраняют прежний путь генерации.
189 исходных привязок заморожены до правок в `freeze_v01`.

Диагностика сохранена. Первый historical import создал один `.pyc` внутри
замороженного snapshot; verifier обнаружил добавленный файл до HTTP проверок.
Исходные файлы не менялись, отсутствующих/изменённых файлов не было. Только
этот добавленный `.pyc` перенесён в `bytecode_quarantine_v01` с SHA и адресами.
Adapter теперь временно отключает bytecode при чтении исторического модуля и
восстанавливает настройку; отдельный тест проверяет manifest до/после.
`review_v01` сохранён, новый `review_v02` повторно измерен. Первоначальные lint
замечания устранены до итоговой проверки; предупреждение Starlette/httpx
сохранено в выводе проверки. Исторические manifests не перезаписаны.

Limitations:

Реальное поведение GigaChat с новым ID контрактом ещё не проверено. Все прежние
live бюджеты закрыты; отправка новых подготовленных запросов требует отдельного
нового согласованного scope. Эти открытые development cases и finite parsers
не дают независимой scientific accuracy. Научная интерпретация Q03 εког/ΔH,
пропущенная страница, независимая оценка, cache/ORM, full suite, browser/PDF
visual QA, concurrency и deployment остаются открытыми. Улучшение latency/cost
не измерялось; уменьшение native bytes не является таким измерением.

Verdict:

Фикс реализован и прошёл локальные проверки, включая HTTP путь с искусственными
ответами. Текст цитат теперь поступает в публичный ответ из серверной привязки,
а успешный результат реальной модели по новому протоколу пока не получен.
План качества остаётся 75% работ; независимая научная приёмка не закрыта.
