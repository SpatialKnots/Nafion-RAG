# ARIADNE BOX: предлагаемый вариант с RTX 5000 Ada

Дата: 16 ноября 2026. Статус: предложение по запросу пользователя оптимизировать сборку; не утверждение закупки.

## Задача и основания выбора

Один специалист, последовательные задания, локальная Qwen 27B как кандидат, PDF/OCR/простые таблицы, поиск, PostgreSQL, проверка источников и экспорт. Пользователь допускает нероссийскую локальную модель для автономного BOX; российский API-профиль сохраняется. Продуктовый end-to-end offline-режим и качество локальной Qwen ещё не доказаны.
Практический выбор среди проверенных магазинных NVIDIA-вариантов с одной GPU и 32 ГБ: RTX 5000 Ada. Это не доказанный глобальный оптимум рынка или measured price/performance. Единственная GPU сохраняет более простой режим размещения модели; 32 ГБ — выбранный ориентир, не гарантия любого контекста и точности весов.

## Изменения относительно RTX 5090-сборки

- GPU: 32 ГБ одной карты сохранены. RTX 5000 Ada вместо RTX 5090; по характеристикам NVIDIA полоса памяти 576 ГБ/с вместо 1792 ГБ/с у 5090, паспортная мощность GPU 250 Вт вместо 575 Вт. Эти значения не равны измеренным скорости токенов и потреблению станции. Производительность может быть ниже; равная скорость не заявляется.
- CPU: 12-ядерный 9900X вместо 16-ядерного 9950X; выбор предполагает одного пользователя и генерацию на GPU, а не доказанную достаточность при любой OCR-нагрузке.
- RAM: 96 ГБ сохранены; 5600 CL46 вместо 6000 CL32. Равная производительность не заявляется. Потребность именно в 96 ГБ не измерена; это запас для локальных весов/импорта/БД, а не минимальное требование.
- Плата: B650 вместо X870E, один основной PCIe 4.0 x16 для Ada. Это не платформа, выбранная для будущих двух GPU; наличие второго физического x16-разъёма само по себе не доказывает равноправный режим двух GPU. Такой режим в этом подборе не проверялся.
- Воздушный AK620 вместо СЖО; корпус с четырьмя штатными вентиляторами; 850 Вт вместо 1200 Вт. Требуются реальные испытания совместной нагрузки.
- SSD PCIe 4.0 TLC вместо PCIe 5.0; измеренного преимущества 9100 PRO на целевой задаче нет. 2 ТБ не заменяют внешнего резервного хранения.

## Проверка технической основы и ограничения

MSI официально заявляет Ryzen 9000, DDR5 non-ECC unbuffered, основной PCIe 4.0 x16; нужный BIOS конкретной поставки и QVL именно CP2K48G56C46U5 не подтверждены. Совместимость по семействам не равна испытанию полной сборки. Есть Flash BIOS Button; обновление не выполнялось.
Производитель MONTECH задаёт ATX, GPU до 400 мм, CPU-кулер до 180 мм и 4x140 мм вентилятора. AK620: AM5, высота 160 мм, clearance RAM 43 мм. Высота конкретных поставляемых модулей и кабельные зазоры должны быть сверены сборщиком; условие по максимальной высоте кулера выполняется по паспортам.
NVIDIA указывает RTX 5000 Ada: 32 ГБ GDDR6 ECC, PCIe 4.0 x16, 250 Вт, активное охлаждение. Артикул 900-5G132-2240-000 как RTX 5000 ADA 32GB независимо подтверждён в ASUS Server Platform AVL; не смешивать с более старой RTX 5000 другого поколения. В карточке Регарда гарантия 12 месяцев и поставка OEM, комплектность питания должна быть явно указана продавцом.

Ни установленной станции, ни замеров Qwen Q6/контекст 16384, ни OCR/performance/offline/scientific acceptance испытаний нет. Размер GGUF не равен пиковой VRAM. 32 ГБ не означают полное размещение Qwen 27B BF16 со всеми буферами; выбранный режим Q5/Q6 и мультимодальная часть подлежат измерению. Модель в рамках подбора не скачивалась; API/OAuth-вызовов не было.
