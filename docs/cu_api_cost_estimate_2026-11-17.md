или её маскировка в статье российского API не предусматриваются.

## Основание расхода токенов

Сохранённые фактические серии:

- [26 запросов ответа](fan_doi_besenhard_answers_live_2026-11-13.md):
  247371 входных + 4345 выходных = 251716 токенов;
- [30 запросов переписывания](fan_doi_besenhard_rewriting_live_2026-11-13.md):
  10183 входных + 2581 выходных = 12764 токена.

Средний ответ: 251716 / 26 = 9681,38 токена; среднее переписывание:
12764 / 30 = 425,47 токена. Их сумма — **10106,85 токена** как приближение
стоимости цикла; это не измеренное среднее 30 успешных полных циклов:
число запросов двух стадий различается, есть отказы и удержанная выдача.
При текущей цене Cloud.ru Max такой средний цикл расчётно стоит 5,75 ₽.
Историческая денежная стоимость прогонов остаётся неизвестной;
новые цены не подменяют старые счета, precached токены не прибавлены повторно.

Для планирования предлагается **12000 токенов на цикл суммарно по обеим стадиям**.
Это допущение для текущего QA-процесса, а не измеренный верхний предел.
При развитии полного извлечения таблиц, длинных контекстах и дополнительных
модельных проверках требуется отдельный расчёт. Число токенов определяется
usage провайдера; приблизительный whitespace-счётчик приложения не биллинг.

## Расчёт на выбранные 10000 циклов

Формула: стоимость = вход / 1000000 × цена входа + выход / 1000000 × цена выхода.
Для Max ставки равны, поэтому можно использовать сумму входа и выхода.

| --- | ---: | ---: | ---: | ---: | ---: |
| Выбранная пользователем основная годовая нагрузка | 10000 | 12000 | 120000000 | 68320,4880 | 78000 |
| Предлагаемые отдельные development/регрессионные прогоны | 2500 | 12000 | 30000000 | 17080,1220 | 19500 |
| **Предлагаемый общий объём** | **12500** | **12000** | **150000000** | **85400,6100** | **97500** |

Дополнительные 2500 циклов — предложение для конкретной экспериментальной
работы, не свободный денежный резерв и не автоматически разрешённые повторы.
Оценка включает оплачиваемые ответы с отказами/ошибками содержания;
повторные обращения при необходимости учитываются как отдельные циклы.
Скидки за кэш, batch и бесплатные личные лимиты не предполагаются.

**Пользователь подтвердил 100000 ₽ на генеративный российский API
на год**, с расчётным сценарием 150 млн токенов Max. По прочитанному текущему
Cloud.ru прайсу точная база — 85400,61 ₽ (85401 ₽ при округлении вверх до рубля);
97500 ₽ — отдельный сценарий действующего договора Сбера, не цена Cloud.ru.
100000 ₽ — одна подтверждённая пользователем строка рабочей сметы,
не дополнительная сумма поверх точного расчёта и не свободный резерв.
Объём закупки и условия определить по доступному организации договору
и сроку финансирования; при изменении потребности пересчитать явно.

Хостинг, GPU-аренда, OCR, embeddings, reranking и хранение не включены:
их фактическая необходимость и объём отдельно не установлены. Текущие
embedding-настройки приложения используют локальные модели; платная
индексация всего корпуса не предполагается автоматически. Научное качество
и требование российского происхождения всех моделей проверяются отдельно.

## История связи со сметой до решения на 4 млн ₽

Прежняя строка 450000 ₽ включала не только API, но и вычислительные ресурсы.
Как бюджет одной генерации Max она соответствовала бы примерно 692,3 млн
токенов по ставке Сбера 650 ₽/млн. Такой объём для выбранной нагрузки
сейчас не обоснован. Отдельная аренда/хостинг не считается оплаченной BOX+.

После подтверждения пользователем основная
[рабочая таблица](cu_grant_budget_working_2026-11-13.md) заменяет прежние
450000 ₽ отдельной строкой API **100000 ₽**. Итог с BOX+ уменьшается
с 4970719 ₽ до 4620719 ₽. Последующее решение пользователя: внешний аудит
после шести месяцев с пределом 100000 ₽ по ГПХ вместо прежних 400000 ₽;
после утверждения ревью кода 250000 ₽ вместо 400000 ₽
и 0 ₽ новых лицензий/данных вместо 150000 ₽ текущий сценарий —
**4020719 ₽**, остальные суммы требуют расчёта.
Уточнение состава BOX: сборка и подготовка входят исключительно в его смету,
ещё не оценены; полный сценарий проекта = 4020719 ₽ + S_BOX+ при сохранении
прочих ориентиров. API остаётся отдельной строкой 100000 ₽.
Прочие вычисления дополнительно не заложены и требуют отдельного расчёта.
Сокращение запроса допустимо рассматривать по реальной потребности,
не заполняя освободившуюся сумму необоснованными покупками.

Changed: зафиксировано подтверждение пользователем API 100000 ₽ и пересчёт
рабочей сметы; личная оплата ChatGPT сохранена, код/модельные бюджеты не менялись.
Tests run: Decimal-расчёт средних, тарифов и сценариев; проверка локальных ссылок.
Limitations: нет коммерческого предложения/договора института, полного годового
плана экспериментов и цены будущего извлечения записей/таблиц; live-тестов нет.
Verdict: API 100000 ₽ подтверждён для рабочей сметы; 10000 основных циклов
расчётно стоят 68320,49 ₽ по текущему Cloud.ru Max, с предложенными 2500
экспериментальными — 85400,61 ₽. Закупка и полная годовая потребность не установлены.
