# Первый внешний эталон: один разрешённый прогон

Вопрос: «Как меняется морфология частиц дисперсии Nafion в зависимости от
природы растворителя?» Пользовательский reference answer и Kim2015 сохранены
до запуска без изменения. Подготовка описана в
`user_reference_001_preparation_2026-10-30.md`.

После отдельного вопроса о ровно одном model POST и одном OAuth пользователь
ответил: «Разрешаю один новый вызов». Исходная zero-budget preparation не
изменена. Approval сохранён отдельно в

## Содержательный результат

Исходный ответ состоит из двух claims. Первый соединяет вводную фразу о
морфологии с повышением температуры разложения мембран на30–40°C в ДМФА,
ДМАА, НМП, цитируя диссертацию с.30–31/E1. Второй описывает набухание Li-Nafion
в водно-спиртовых средах, цитируя Чернюк2024 с.5–6/E4. Модель вернула
answerable=true, runtime принял эти claims.

Отдельное post-hoc сопоставление ассистента с внешним пользовательским
reference: ответ **не описывает запрошенную морфологию частиц**. Ни один из
четырёх пунктов reference не раскрыт: микрогели; цилиндры и размеры в глицерине;
переходы формы при изменении состава; морфологические исходы концентрирования.
Это заключение об одном ответе, не численная оценка общей accuracy.
Термическое свойство и набухание не заменяют описание формы дисперсных частиц.

Kim2015 отсутствовал в фактических пяти фрагментах/трёх выбранных работах.
Ранняя стадия потери Kim (candidate retrieval/ranking/window) здесь ещё не
локализована. Adequacy gate допустил sufficient_distinctive_term_coverage:
matched_terms не включают «морфология» и «частиц», coverage7/9. Такой lexical
coverage не доказал наличие запрошенной научной связи. На стороне генерации
off-target ответ принят вместо отказа. Это наблюдения из trace, не новая
семантическая валидация и не исправление runtime.

## Ограничения и статус

Reference поступил от пользователя до model run; его метод аннотирования и
экспертная проверка не объявлены. Kim/topic ранее встречались в retrieval
fixtures. Source-check и сравнение ассистента не выдаются за независимую
экспертную разметку. Исходный reference не исправлен и не передан модели;
Na-form/2.5wt%/ratio-versus-concentration/NMF уточнения оставлены отдельно.

Первый внешний reference case проверен и выявил провал ответа. Общая научная
accuracy, полнота связей и качество отказов на отдельном наборе не измерены.
Пункт4 открыт; общий план75%. Это не требование успешных ответов для завершения
оценки: даже отрицательный результат должен войти в итоговый отчёт набора.
Все прежние бюджеты и этот новый слот закрыты. Следующий шаг — продолжить
сбор внешнего набора и отдельно локализовать потерю Kim без подгонки этого
случая под статус независимого повторного теста.
